# Checklist SEO (sin promesas de ranking)

- [x] SSR en home, categoría y tema; metadatos básicos y canonical en temas.
- [x] Solo temas publicados en endpoints públicos.
- [ ] Canonical y meta únicas en todas las páginas; evitar duplicados por parámetros.
- [ ] Sitemap paginado con **todos** los temas públicos, fechas reales, sin URLs privadas.
- [ ] JSON-LD `DiscussionForumPosting` solo cuando represente contenido visible real; validar con Rich Results Test.
- [ ] Paginación de categorías rastreable y enlaces HTML reales.
- [ ] 404 y 410 correctos; redirecciones 301 al cambiar slugs.
- [ ] Evitar indexar búsqueda interna, login, páginas vacías y spam.
- [ ] Medir LCP, INP, CLS y rastreo en Search Console.
- [ ] Política editorial, autoría, moderación y contenido original útil.
- [ ] Robots.txt no sustituye noindex ni controles de acceso.
- [ ] Análisis de palabras clave y competidores antes de publicar contenido.
